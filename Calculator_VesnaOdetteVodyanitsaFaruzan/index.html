薇斯纳伤害计算器

在给定配队、装备、流程的情况下，通过改变角色配置，得到对应的dps估计。 Bird of Fischel

使用说明

本文档实现了在给定队伍为薇斯纳、奥黛塔、沃雅妮莎、珐露珊，圣遗物配置为血红、炉火、千岩和宗室的情况下，面对110级、10全抗敌人， 处于中间轮循环的总伤和DPS计算。其中"中间轮循环"是指刚开始的角色也能吃到上一轮循环中还未结束的buff的状态。

在本文档中，用户可以自由 设置角色的圣遗物词条、角色等级、角色命座、角色武器、角色武器精炼的数据。点击"计算面板"或右侧的"初始面板"， 算法将自动计算当前角色在未入队时的初始面板数据和生效效果；当用户点击"前台面板"时，计算当前角色在前台时能吃到的所有增益效果， 展示角色对应的面板和生效效果描述；当用户点击"后台面板"时，则展示当前角色在后台吃到所有增益效果后的面板和相应效果描述。

当用户设置好角色配置时，点击下方的"开始计算"，算法将按照文档内预设的手法计算用户配置下的输出循环的各段伤害、总伤和对应的DPS。 用户可以点击"各段伤害计算表"的表头序号，得到每段伤害计算的细节，包括伤害计算表达式、当前角色面板和生效效果 (由于舍入误差问题，伤害计算表达式两端的数值并不完全相等)。

在伤害计算过程中，为了简化计算，文档中定义了"重复次数"变量，指在一轮循环中重复出现的、受增益效果不变的多次同类型伤害的次数， 文档中将这类伤害合并处理(如X次星扩散风伤、X次星扩散冰伤)，并在伤害表达式中定义"重复次数"为一个乘区参与计算。 特别地，当攻击具有羽毛增益时，羽毛增益的计算结果本身就考虑了"重复次数"影响，故表达式中羽毛增益不会与"重复次数"相乘。

手法说明

无论什么配置，循环手法都为"奥黛塔EE -> 珐露珊EQ -> 沃雅妮莎E -> 薇斯纳一套"，其中薇斯纳一套的手法随命座变化有区别。 文档中假设薇斯纳普攻或重击需要4次才能攒满一层剑气，非6命薇斯纳需要通过普攻或重击的方式，无Q时攒满3层剑气，有Q时攒满2层剑气。 考虑到手法：(1) a1a2耗时1s，倍率1.761，攒0.5层剑气，攒2层需4s，攒3层需6s； (2) a1-a4耗时2.25s，倍率4.041(秒均1.796)，攒1层剑气，攒2层需4.5s，攒3层需6.75s； (3) a1-a6耗时3.45s，倍率6.703(秒均1.943)，攒1.5层剑气，攒3层需6.9s； (4) a1-a3+z耗时3.25s，倍率5.501(秒均1.693)，攒1层剑气，攒2层需6.5s，攒3层需9.75s； 考虑到在珐露珊队伍中轴长至少19秒，队友耗时：奥黛塔2.5s，珐露珊2s，沃雅妮莎1s，薇斯纳可以站场约13.5秒； 薇斯纳打完 "e0(开启战技)+e1e2+e3*3" 的时间是5.79秒，"e0+e1e2+e3*4" 的时间是7.12秒，开大的时间是2.5秒，因此：

薇斯纳C0: (1)有Q时：e0 -> e1e2 -> q -> e3 -> a1a2a3a4 -> e3 -> a1a2a3a4 -> e3; (2)无Q时：e0 -> e1e2 -> a1a2a3a4a5a6 -> e3 -> a1a2a3a4a5a6 -> e3 -> e3；

薇斯纳C1-C5 (1)有Q时：手法为 e0 -> e1e2 -> a1a2 -> e3 -> a1a2 -> q -> (e3 -> a1a2)*2 -> e3； (2)无Q时：e0 -> a1a2 -> e1 -> a1a2 -> e2 -> a1a2 -> e3 -> a1a2 -> (e3 -> a1a2)*2 -> e3；

薇斯纳C6：(1)有Q时： e0 -> e1e2e3 -> step -> q -> (e3 -> step)*3 (step表示6命效果"变移") (2) 无Q时： e0 -> e1e2e3 -> step -> (e3 -> step)*3
